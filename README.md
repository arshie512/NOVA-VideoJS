# NOVA — The Living Frame

NOVA is an original Video.js v10 player skin inspired by an instrument panel in a living forest. Its contour-line timeline, geometric aperture play/pause control, editorial time readout, and spatial volume/fullscreen controls frame an original dinosaur encounter.

The five-second, 4K forest fight features a T. rex and a Triceratops with an original fight soundtrack. The complete visual preview is in `public/NOVA-player-preview-4K.mp4`; it shows the player controls over the moving footage. Those controls are visual in the preview video. The interactive controls are available when the React app is running.

## Run the interactive player

```sh
pnpm install
pnpm dev
```

Open the local address printed by Vite. The player includes play/pause, seeking, elapsed and total time, volume, mute, fullscreen, keyboard controls, and responsive layouts.

## Build

```sh
pnpm build
```

## Keyboard controls

- `Space`: play or pause
- `←` / `→`: seek
- `M`: mute or unmute
- `F`: enter or exit fullscreen
